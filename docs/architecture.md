# 技术设计说明

## 1. 目标与边界

悟真鉴引的目标不是给论文打一个“真假分数”，而是把引文问题拆成可以分别验证的证据：

1. 文献题录能否在公开来源中找到。
2. DOI、标题、作者、年份、期刊等字段是否一致。
3. 正文引用能否映射到参考文献表。
4. 文献是否已被撤稿。
5. 正文主张是否有摘要或开放全文证据支持。

系统明确区分“未找到”和“不存在”，也不在缺少证据时输出确定性的支持或不支持结论。

## 3. 模块职责

### `app.py`

- FastAPI 应用与静态资源挂载。
- 任务创建、后台执行、SSE 进度推送。
- 报告查询、补充 DOI、导出、分享和二维码。
- 安全响应头、上传大小限制和公开源模式判定。

### `backend/documents.py`

- 读取 PDF、DOCX、TXT、Markdown。
- PDF 使用 `pypdf` 提取文本；没有文字层时提示 OCR。
- DOCX 读取段落和表格。
- 通过独立分节标题切分正文与参考文献。
- 支持中英文标题变体，例如 `参考文献`、`References`、`Bibliography`、`Works Cited`。

### `backend/references.py`

- 参考文献条目切分：编号列表、无编号列表、跨行 DOI 拼接。
- 字段解析：标题、作者、年份、DOI、期刊、卷期、页码、PMID、arXiv ID、ISBN。
- 正文引用识别：数字引用、区间引用、全角标记、作者年份引用。
- 本地完整性检查：字段缺失、重复文献、编号重复/中断、正文引用缺失、文献表未引用。

### `backend/sources.py`

- 有 DOI：并行查询 Crossref、DataCite、OpenAlex。
- 无 DOI：Crossref 书目检索 + OpenAlex 题名检索。
- 多字段匹配评分：标题相似度、作者重合度、年份、期刊、DOI。
- 撤稿检测：Crossref `updated-by` 与 OpenAlex `is_retracted`。
- 可选知网授权桥接结果合并。
- 对 429/5xx 做一次重试；支持 polite pool 联系邮箱。

### `backend/agent.py`

- 串联解析、映射、核验、证据判断和报告生成。
- 规则辅助支持度判断：中文按 bigram，英文按词元。
- 可选大模型增强：只允许解释已有证据，证据引文必须能在原文中找到。
- 生成结论、风险清单、证据矩阵、质量画像、修订建议和 Markdown 报告。
- `rebuild_report_derived()` 在补充 DOI 后重算派生数据。

### `backend/exports.py`

- Word：完整报告。
- Excel：核验结论、问题清单、文献明细、正文证据链。
- PDF：报告摘要、问题清单、逐条文献和边界说明。
- JSON：结构化报告。

### `backend/store.py`

- 内存存储：适合本机演示和开发。
- PostgreSQL 存储：任务与分享持久化。
- 任务和分享均带 TTL，读取时校验，避免过期链接继续可访问。

### `backend/cnki.py`

- 可选的机构授权知网桥接。
- 通过本地 Chrome DevTools Protocol 会话执行检索，不保存账号密码。
- 默认只对本机请求开放；公网部署时关闭。

## 4. 核验状态模型

### 题录状态

| 状态 | 触发条件 |
|---|---|
| `verified` / 已证实 | 标题高度相似，且作者、年份等字段满足匹配阈值 |
| `possible_match` / 可能匹配 | 找到候选，但字段未完全对齐 |
| `conflict` / 信息冲突 | DOI 指向其他记录，或作者/年份存在明确冲突 |
| `not_detected` / 暂未检出 | 当前公开来源没有找到足够可靠的候选 |
| `coverage_insufficient` / 覆盖不足 | 数据源未覆盖或请求失败，不能据此判断 |

### 正文支持度

| 状态 | 触发条件 |
|---|---|
| `supported` / 支持 | 正文主张与证据词汇重合度较高 |
| `partially_supported` / 部分支持 | 存在主题重合，但不足以完全支持 |
| `not_supported` / 不支持 | 仅在模型明确否定且证据可核验时出现 |
| `insufficient_evidence` / 证据不足 | 没有摘要、开放全文或有效证据 |
| `not_checked` / 未判断 | 粘贴模式未提供正文 |

### 撤稿状态

撤稿是独立布尔标记，不改变题录匹配结论：

- Crossref：`updated-by` 中存在 `type: retraction`。
- OpenAlex：`is_retracted: true`。
- 命中后：文献风险等级设为高，生成“已撤稿文献”问题项，并在报告、导出中展示。

## 5. 匹配与判断逻辑

### 标题相似度

使用规范化后的 `SequenceMatcher` 比率。中文会去除字符间空格，英文统一小写并去除标点。

### 作者重合度

提取英文姓氏/名字词元和中文姓名，排除 `and`、`et`、`al` 等停用词，计算交集占较短作者集合的比例。

### 综合判断

- 标题高度相似 + 年份一致 + 作者对齐：已证实。
- 标题相似但作者或年份冲突：信息冲突。
- 只有标题相似：可能匹配。
- 候选不足：暂未检出。
- 中文无 DOI 且无授权源：覆盖不足。

### 支持度规则

- 没有证据：证据不足。
- 词汇重合度 ≥ 0.4：支持。
- ≥ 0.15：部分支持。
- 否则：证据不足，不直接判“不支持”。

## 6. 数据流

1. 上传文件或粘贴文献列表。
2. 解析文档，切分正文与参考文献。
3. 解析参考文献条目和正文引用。
4. 本地完整性检查。
5. 并发核验每条文献的题录。
6. 合并候选、计算匹配状态、检测撤稿。
7. 对正文引用逐条判断支持度。
8. 生成结构化报告和 Markdown。
9. 返回报告；按需导出或分享。

## 7. 存储与生命周期

- 默认内存存储：进程退出即清空。
- PostgreSQL：`jobs` 表保存任务 JSON，`shares` 表保存分享令牌。
- 默认 TTL 为 2 小时；可通过 `JOB_TTL_SECONDS` 调整。
- 读取任务和分享时校验 TTL，过期返回 404。
- 上传原文不写入磁盘，也不进入分享链接。

## 8. 安全设计

- 上传大小限制，默认 20 MB。
- API 响应 `Cache-Control: no-store`。
- 安全响应头：`X-Content-Type-Options`、`Referrer-Policy`、`X-Frame-Options`。
- 分享报告默认脱敏，隐藏论文来源名称。
- 补充 DOI 仅允许本机请求。
- 公网访问自动关闭知网授权检索。
- 不保存机构账号密码，只复用本机浏览器会话。

## 9. 测试策略

测试以离线单元测试和集成测试为主：

- 文档解析与分节。
- 参考文献、引用和本地检查。
- 外部来源匹配逻辑。
- 撤稿关系识别。
- 任务、分享和 TTL。
- 四种导出格式的真实文件生成。
- 粘贴模式不输出语义判断。

运行：

```bash
python -m pytest -q
```

## 10. 已知限制

- 中文无 DOI 文献依赖机构授权数据库；公网模式覆盖有限。
- 扫描版 PDF 需要先 OCR。
- 摘要证据依赖数据源是否返回摘要；很多付费文献没有公开摘要。
- 撤稿检测依赖 Crossref/OpenAlex 的登记信息。
- 引用格式修订目前只给建议，不做自动重排。
- 大模型增强是可选项，启用后证据文本会发送给模型服务。
