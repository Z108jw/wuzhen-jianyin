免登录 · 公开源核验

打开网页，
就能开始核验引用。

不需要账号、学校 VPN 或知网登录。粘贴参考文献或读取 TXT/Markdown，就会检查重复条目、编号、字段、DOI，并通过 Crossref/OpenAlex 公开来源核验。页面本身不保存你的材料。

核验边界
“暂未检出”只表示当前公开来源没有找到对应记录，不等于文献不存在。
CrossrefOpenAlex本地规则提交前人工复核

01 / Input

提交需要核验的材料

免登录版支持文献列表与纯文本；PDF、DOCX、撤稿检测和 Word/PDF 报告由服务器完整版处理。

文献题录只用于向 Crossref/OpenAlex 发起公开检索，不会上传到本页自己的服务器，页面也不保存材料。

正在检查文献结构。
当前为免登录公开源版，只使用 Crossref/OpenAlex 公开数据。上传 PDF/DOCX、撤稿检测和 Word/PDF 导出需另行部署完整版后端。

02 / Method

先检查结构，
再查询公开来源。

  1. 解析识别文献编号、标题、作者、年份和 DOI。
  2. 体检检查重复、编号中断、字段缺失和引用关系。
  3. 核验有 DOI 时先解析，无 DOI 时用题名检索。
  4. 报告生成可展开、可打印、可导出的核验结果。
本页不会凭标题自动认定“支持正文结论”，也不会把“未检索到”写成“文献不存在”。
